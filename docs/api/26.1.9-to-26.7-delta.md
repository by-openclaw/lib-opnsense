# OPNsense API schema delta — 26.1.9 → 26.7 CE

> Captured with `scripts/probe-api-schemas.sh` against a live full **ZFS 26.7 CE**
> install (vm-opns-lab-01). Data: [`data/26.7/`](data/26.7/) vs [`data/26.1.9/`](data/26.1.9/).
> The probe walks a fixed endpoint list, so **file-sets are identical**; the delta is in
> schema *content* (fields/enums) and in **new controllers** found by route discovery
> (`data/26.7/endpoints.txt`, 812 endpoints / 117 controllers — see coverage-26.7.md).

## Content changes
**205 endpoint schema/search files changed** between 26.1.9 and 26.7, spanning nearly every
domain (auth, firewall, dhcp/dnsmasq, ids, ipsec, interfaces, core, crowdsec, …). Field-level
churn — new fields, enum options, defaults. Managers keep working (the lib is version-tolerant),
but validators may warrant a refresh where enums grew.

## Interfaces — what 26.7 makes API-manageable (was config.xml/seed-only)
Route discovery on 26.7 shows the `interfaces` module now has full MVC controllers
(`add_item/set_item/del_item/get_item/search_item/reconfigure`):

| Controller | 26.7 live | Lib manager | Moves off the seed? |
|---|---|---|---|
| `interfaces/vlan_settings` | ✅ 200 | `interfaces/vlan.py` | **Yes — VLANs via API today** |
| `interfaces/vip_settings`  | ✅ 200 | `interfaces/vip.py`  | **Yes — VIPs via API today** |
| `interfaces/bridge/lagg/gif/gre/vxlan/neighbor` | ✅ | present | Yes |
| `interfaces/assignment` (NIC → logical wan/lan/optN) | ✅ 200 (`search_item`) | **MISSING** | **New build — moves interface *assignment* off the seed** |
| `interfaces/settings` (get/reconfigure) | ✅ | n/a | global toggles only; no per-interface `set` |

**Bottom line:** on 26.7, VLANs/VIPs/bridge/lagg/etc. are already lib-managed via the API, so
they no longer need the seed. **Interface assignment** is newly MVC and needs one new manager
(`interfaces/assignment`) to move NIC→logical mapping off the seed too. **Per-interface IP
addressing** still has no clean MVC `set` (only `interfaces/settings` get/reconfigure), so the
initial IP/addressing of an interface likely remains a seed/config.xml concern for now —
confirm when building the assignment manager.
